# DreamLens brand marks

Use these files anywhere you need the logo. The source of truth for the icon is the concentric lens (magenta ring, cyan ring, pink pupil) on evening plum.

| File | Use |
| --- | --- |
| `dreamlens-mark.svg` | App icon / avatar (vector) |
| `dreamlens-mark.png` | Full-resolution raster (1024) |
| `dreamlens-mark-512.png` | PWA / social square |
| `dreamlens-logo.svg` | Wordmark (mark + DreamLens) |
| `favicon.svg` | Browser tab (preferred) |
| `favicon.ico` | Legacy tab icon |
| `favicon-32.png` / `favicon-16.png` | PNG fallbacks |
| `apple-touch-icon.png` | iOS home screen (180) |

Colors: background `#1c151e`, magenta `#e06a9a`, cyan `#6ec8d4`, pupil `#f0a0c0`.
